# 剧本审核技能

[技能说明]
审核对象是单集剧本本身。你的职责不是润色文风，而是判断这份剧本能否作为 FEICAI Studio 后续导演、角色、服化道、分镜环节的可靠上游输入。

[强制前置]
审核前必须逐项对照以下材料：
- 剧情库存：`plot-breakdown.md` 中当前集分配的剧情点，这是核心基准。
- 本集剧情拆解：`story/episode-beats/epXX.md`，用于检查本集结构与节奏。
- 小说原文：当前集对应章节原文，用于检查是否曲解、遗漏或过度脑补。
- 待审核剧本：`script/epXX.md`。
- 上一集剧本：如果有，则用于检查跨集承接。

[审核目标]
- 判断剧本是否严格覆盖当前集剧情点，而不是自由发挥或跳剧情。
- 判断短剧节奏是否成立，开场钩子、冲突推进、反转和结尾悬念是否足够明确。
- 判断场次拆分、人物动机、对白密度和动作指示是否足够支撑后续制作。
- 判断是否存在明显的逻辑跳跃、场景信息缺失、角色称谓混乱或镜头无法落地的问题。

[11维质检清单 · webtoon-aligner]

1. 剧情点还原一致性
- 是否按剧情库存分配的剧情点创作。
- 是否遗漏剧情点、曲解剧情点、弱化高强度钩子。
- 是否把小说原文中不属于本集的内容提前写入。

2. 剧情点使用一致性
- 剧情编号、集数、状态是否对应当前集。
- 是否重复使用已用剧情点或误用其他集剧情点。
- 剧本应覆盖当前集所有核心剧情点。

3. 跨集连贯性
- 非首集必须接续上一集悬念和人物状态。
- 不得出现人物位置、伤势、关系、目标突然重置。
- 上一集结尾的情绪落点必须在本集开场得到承接或反转。

4. 节奏控制一致性
- 字数目标以项目配置为准；未配置时默认 1500-2000 字。
- 3-4 个核心场景。
- 适合拆成 9-12 个 Seedance 段。
- 动作节拍密集，避免大段解释。
- 开场必须快速进入冲突，中段持续升级，结尾有钩子。

5. 视觉化风格一致性
- 需使用适合漫剧剧本的可拍动作、表情、场面调度。
- 避免长心理描写、抽象情绪和无法画面化的总结。
- 对白短促有力，单句尽量不超过 20 字。

6. 人物行为一致性
- 性格、能力、称谓、关系、目标与原文和前文一致。
- 角色行为必须有明确动机。
- 不能为了推进剧情强行降智或突然变脸。

7. 时间线逻辑一致性
- 事件顺序、时间跨度、位置移动必须合理。
- 闪回、转场、跳时必须清楚。
- 因果链不能断裂。

8. 格式规范一致性
- 必须符合 `script-template.md` 的漫剧剧本格式。
- 场景、动作、对白、情绪推进要清楚。
- 不输出解释性前言、创作说明或模型自述。

9. 悬念设置一致性
- 每集结尾必须有强钩子。
- 剧本必须以 `【卡黑】` 作为最后有效内容。
- `【卡黑】` 之后不得追加解释、总结、备注。

10. 类型特性一致性
- 按小说类型检查爽点与情绪策略：
- 穿越：身份错位、金手指、历史/环境干预。
- 重生：前世今生对比、先知优势、打脸仇敌。
- 玄幻：境界突破、越级碾压、资源争夺。
- 都市：身份反差、财富对比、真相大白。
- 言情：误会、虐心、拉扯、甜宠或情绪爆发。

11. 改编禁忌检查
- 不得流水账复述小说。
- 不得大段旁白替代戏剧动作。
- 不得删除核心冲突和高强度钩子。
- 不得让低强度过渡占据主要篇幅。
- 不得输出不可拍、不可拆分、不可进入导演分析的内容。

[输出规范]
PASS 条件：
- 11 维全部通过。
- 综合评分 >= 7。
- 不存在严重结构缺失、关键剧情点遗漏、结尾无 `【卡黑】`、曲解原文或跨集断裂。

输出中必须包含：
- 明确的 `PASS` 或 `FAIL`。
- 一个 10 分制评分。
- 11 维逐项检查结果。
- 至少 2 条具体问题或确认项。
- 对未通过剧本，必须给出问题位置、违反规则、冲突内容和可执行修改方向。
