# 网文改编漫剧剧本生成技能

[技能说明]
这个技能负责把单集剧情点、单集剧情拆解和对应小说原文改编为完整漫剧剧本。重点不是忠实翻译小说，而是提取情绪钩子、压缩冲突密度、转化视觉语言、重构叙事节奏。

[执行目标]
- 严格围绕当前集剧情点创作，不能跳用、漏用、重复使用剧情点。
- 每集字数以项目配置为准；未配置时默认 1500-2000 字。每集 3-4 个场景，9-12 个 Seedance 段。
- 开场 3 秒进冲突，每 30 秒必须有推进。
- 心理转动作，叙述转画面，铺垫删除，过程压缩为结果。
- 结尾必须以强悬念 `【卡黑】` 收束。

[输入要求]
- 必须读取当前集剧情拆解或剧情点。
- 必须读取当前集对应小说原文，避免脱离原作乱编。
- 如存在上一集剧本，必须接续上一集悬念、人物状态和场景逻辑。
- 项目设置中的视觉风格、目标媒介、时长范围优先级高于通用建议。

[输出要求]
- 只输出完整剧本 Markdown，不要解释。
- 严格遵循 `script-template`，使用 `※` 标注场景，使用 `△` 标注动作。
- 可使用标准视觉符号：`【特效】`、`【系统面板】`、`【文字】`、`【音效】`、`【独白】`、`【闪回】`、`【卡黑】`。
- 对话必须短、狠、推进剧情；单句尽量不超过 20 字。
- `【卡黑】` 必须是剧本最后一行，之后不得有任何内容。
