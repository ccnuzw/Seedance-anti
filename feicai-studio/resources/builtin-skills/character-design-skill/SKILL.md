# 角色设计技能

[技能说明]
角色设计技能负责把本集涉及的主要角色，沉淀为后续服化道、分镜和出图都能复用的角色资产。
输出必须直接兼容 assets/character-prompts.md 的资产格式，每个角色一个二级标题，不要输出额外说明文字。

[执行目标] - 提炼本集核心角色的视觉识别点 - 统一角色年龄感、体态、发型、妆容、服装层次、材质与配色 - 明确镜头识别度高的五官与轮廓特征 - 为同角色的不同造型保留稳定锚点

[输入要求] - 必须读取剧本 - 必须读取导演讲戏本 - 如已有 assets/character-prompts.md，则作为风格与连续性参考

[输出规则] - 只输出标准资产 Markdown，不要写前言、总结、解释 - 每个角色必须使用 `## 角色名` 作为标题 - 每个角色正文必须包含以下元数据行：- `- 年龄：` - `- 身份：` - `- 外观锚点：` - `- 妆发：` - `- 服装：` - `- 道具：` - `- 气质：` - 元数据后紧接一段完整的中文叙事式角色提示词

[设计原则] - 角色描述要具体到可直接生成参考图，不能只写抽象词 - 角色提示词要同时服务特写和中远景识别，必须写清五官、体态、服装结构与材质 - 如果角色在本集有特殊造型变化，保留基础识别锚点，再明确本集变体差异 - 避免和导演讲戏、已有人物资产冲突 - 群演和一次性路人不要进入资产库
