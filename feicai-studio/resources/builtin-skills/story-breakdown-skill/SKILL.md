# 网文改编剧情拆解技能

[技能说明]
这个技能负责把小说章节改编为漫剧剧情点清单。重点不是复述原文，而是从原文中提取高强度情绪钩子，删除铺垫、心理描写、过渡情节和无关支线，把可拍、可爽、可连续创作的剧情点沉淀出来。

[执行目标]

- 按小说顺序读取当前章节范围，识别核心冲突和情绪钩子。
- 只保留有原文依据且达到项目质量要求的剧情点；不得为凑数量虚构或强化事件。
- 将剧情点标注到目标集数，分集服从叙事容量和项目配置。每集 3-4 个仅为通常建议，不是硬指标；可少于或多于，避免单集过载，并明确跨集转折及因果承接。
- 输出必须服务后续剧本创作，场景、角色、事件、情绪钩子、集数、状态都要明确。

[事实依据与确定程度]

- 每个剧情点都必须能对应当前批次原文中的具体事件证据；不要求照抄原文，但不得添加原文没有确认的身份、行为、因果、计划、心理意图或结果。无法映射到证据的内容不输出。
- 区分可观察事实与解释：身份/行为/因果/意图分别按原文确定程度表达。原文只是暗示、角色猜测、画面转场或存在多种解释时，明确写“疑似”“可能”“尚未确认”等，或省略该推断；不能把疑似升格为事实。
- 不得仅凭沉默、表情、停顿或镜头切换断定角色的动机、授意、决定、隐藏计划或主动选择。钩子标签必须与已发生或明确呈现的事实相符；例如自尽行为被阻止、现场切换或人物醒来，不足以标注“重生”。

[安全与适配]

- 明确为未成年人的角色不得被性化，不描写裸露、以身体换取偏爱/利益或性剥削内容；不得通过改称成年、删去年龄线索或润色来规避其未成年身份。
- 不细化虐待、自伤、毒害等伤害行为的方式、过程或可模仿细节，不美化或鼓励伤害。优先省略不必要的侵害镜头，聚焦非图像化后果、保护与求助。
- 这些生成规范不代表有害源情节可自动通过审核。来源内容本身无法安全适配时，明确标记阻塞并交由既有严格合规审核；不得以改写保证 PASS。

[输入要求]

- 必须基于当前集或当前批次对应的小说章节原文。
- 如存在已有剧情拆解或剧情点库存，必须延续剧情编号、分集逻辑和状态管理。
- 项目设置中的总集数、每集章节数、视觉风格、目标媒介优先级高于通用建议。

[输出要求]

- 优先输出 `plot-breakdown-template` 所定义的剧情点格式。
- 剧情点必须使用：`【剧情n】[场景]，[角色A]对[角色B][做了什么]，[情绪钩子类型]，第X集，状态：未用`
- 不要输出小说梗概，不要输出长篇分析，不要照搬原文。
- 必须体现“提取不是翻译，重构才是王道”的改编原则。
