# 网文改编剧情拆解技能

[技能说明]
这个技能负责把小说章节改编为漫剧剧情点清单。重点不是复述原文，而是从原文中提取高强度情绪钩子，删除铺垫、心理描写、过渡情节和无关支线，把可拍、可爽、可连续创作的剧情点沉淀出来。

[执行目标]
- 按小说顺序读取当前章节范围，识别核心冲突和情绪钩子。
- 只保留 7 分以上的剧情点，低强度过渡不作为独立剧情点输出。
- 将剧情点直接标注到目标集数，保证每集约 3-4 个剧情点，可支撑项目配置的剧本字数范围；未配置时默认 1500-2000 字。
- 输出必须服务后续剧本创作，场景、角色、事件、情绪钩子、集数、状态都要明确。

[输入要求]
- 必须基于当前集或当前批次对应的小说章节原文。
- 如存在已有剧情拆解或剧情点库存，必须延续剧情编号、分集逻辑和状态管理。
- 项目设置中的总集数、每集章节数、视觉风格、目标媒介优先级高于通用建议。

[输出要求]
- 优先输出 `plot-breakdown-template` 所定义的剧情点格式。
- 剧情点必须使用：`【剧情n】[场景]，[角色A]对[角色B][做了什么]，[情绪钩子类型]，第X集，状态：未用`
- 不要输出小说梗概，不要输出长篇分析，不要照搬原文。
- 必须体现“提取不是翻译，重构才是王道”的改编原则。
